# GolfTrace

iOS 练习场视频轨迹 MVP：固定机位拍一段击球，用系统 Vision 自动画球路，检测失败时暂停后点选补线，再导出到相册。

## 需要什么

本机目前只有 Command Line Tools，**要安装完整 Xcode** 才能编到模拟器或真机。

- Xcode（iOS 17+ SDK）
- 真机更准：Vision 轨迹检测需要镜头和背景基本不动

## 打开工程

```bash
open GolfTrace.xcodeproj
```

选一个 Development Team，连 iPhone 或模拟器后 Run。模拟器没有相机，用相册里的挥杆视频即可。

## 怎么用

1. 把手机固定好，球和飞行过程都要在画面里。
2. **拍摄视频** 或 **从相册选择**。
3. 自动识别轨迹；不行就暂停，在球的位置点几下。
4. **导出到相册** 得到带轨迹的视频。
